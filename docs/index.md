# MapThat public information

MapThat is an experimental Instagram messaging service operated by Martin Janus.
The current prototype tests receiving a message and sending a fixed
acknowledgement. Reel-to-location extraction is not available in this version.

- [Privacy policy](privacy.html)
- [Data-deletion instructions](data-deletion.html)
- [Contact MapThat](mailto:appmapthat@gmail.com)

These pages explain the current experiment. They are not a sign-up page or an
announcement of public availability.
